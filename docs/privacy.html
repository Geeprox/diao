Privacy policy

Diao uses browser data to organize open tabs, watch tasks and help you revisit ChatGPT conversations. This policy covers Diao 0.5.

Tabs and reminders
Diao reads open tab titles, addresses, groups and recent activity in regular Chrome windows. On pages you allow it to access, Diao can track task status and changes in a region you select. Watch settings stay in your Chrome profile. Recently closed tabs are available for 30 minutes during the current Chrome session. Opening links together with their source tab is handled in Chrome.
ChatGPT tools
With ChatGPT access enabled, Diao reads questions, replies, headings and selected text to build the outline and place annotations. Diao stores annotations and overview results locally. Queued messages use the ChatGPT composer and send controls, and the messages you send go to ChatGPT.
Requests to your model provider
When you use model-powered tab analysis, Diao sends the title, address without query or fragment, up to 1,600 characters of readable text and signals about page state. If you enable smart grouping and shelving, Diao uses the same data from allowed pages plus source-tab relationships, group and position, and time since last use to organize open tabs automatically. It moves finished tabs into the Idle tabs group so you can reopen the group later.
Conversation summaries send readable questions, reply text, headings and indicators for image replies to the configured OpenAI connection. In preparation mode, this can start when the current conversation is idle, before you open the overview. If more history becomes available, Diao uses it to update the overview and reuses cached results for matching content. Choose the original and cached view in the ChatGPT settings to turn off new summary requests.
Diao sends requests directly to the HTTPS endpoint you configure, with its API credential. Your model provider's privacy and retention policies apply to the data it receives.
Model connection and Chrome Sync
You can keep a key for the current session or save it in your Chrome profile's encrypted storage. Chrome Sync sends the encrypted key, connection settings and public parameters needed to unlock it to Google's sync service. A device restores the connection after a passkey or pairing code unlock. Conversation summaries and annotations stay out of the connection sync record. A compatible Mac helper can also use macOS Keychain when you choose that storage option.
Diao Bridge
The optional Mac helper uses Accessibility access to locate Chrome windows and tabs so it can place tab-side reminders and show the keyboard switcher. It exchanges the window and tab state needed for these features with the extension on your Mac. You can manage that access in macOS System Settings.
Manage your data
In Diao, you can stop watching tasks, remove annotations and remove your saved key. To remove a shared key, use Remove from sync in Model connection. Uninstalling Diao clears its local Chrome data. To remove a saved Keychain entry, remove the key before uninstalling the helper.

Diao's use of information follows the Chrome Web Store User Data Policy, including its Limited Use requirements.
