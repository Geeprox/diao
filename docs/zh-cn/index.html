知道后台任务何时完成，把相关的 Chrome 标签放在一起，在 ChatGPT 长会话里直接找到你要的那一段。

添加到 Chrome

标签提醒

在任务页面点右键，选择开始监听。任务完成会提醒你。页面状态需要帮助识别时，点一次进度文字即可。

ChatGPT 大纲与摘要

搜索问答和章节，点击回到原文，捏合打开对话概览。连接 OpenAI 后可提前准备主题归纳和逐轮摘要。

自动分组

新开的链接可以和来源页放在一起。连接模型并授权后，还能按任务内容归拢不同网站的标签，把已完成的页面收进「闲置标签」。

安装与使用

一定要用 Mac 吗？
网页监听、标签整理和 ChatGPT 工具可直接在 Chrome 中使用。Diao Bridge 为 Apple 芯片、macOS 27.2 或更新版本的 Mac 提供标签旁提醒、可见时续计的倒计时和 Control + Tab 切换。
怎么在新电脑使用已保存的连接？
在「模型连接」选择「Chrome 同步」。另一台设备登录同一 Chrome 账号后，用通行密钥或配对码解锁一次。也可以给单台设备保留独立的 Key。
Diao 和 Tab Cadence 是什么关系？
Diao 是 Tab Cadence 的新名字。安装和更新继续使用同一个 Chrome 商店条目。
