Diao 把 Chrome 标签管理、后台任务提醒和 ChatGPT 对话大纲放在一起。

• 监听后台任务。在任务页面右键选择「开始监听」，Diao 会自动识别常见状态，完成时提醒你。需要帮助识别时，点一次进度文字，之后可以复用。
• 在 ChatGPT 找回原文。搜索提问与回答章节，点击直达原文。也能选文字做批注，并在当前回答期间排队下一条问题。
• 捏合查看概览。连接 OpenAI API Key 后，概览显示对话总览、主题和带原文定位的逐轮摘要。开启提前准备后，Diao 会在前台会话空闲时生成，并复用缓存。
• 把相关标签放在一起。通过 Chrome 原生分组把新链接与来源页放在一起。开启智能整理后，模型可判断哪些跨站页面属于同一个任务，或把已完成的闲置页面收起。随时可从标签栏找回。

网页监听和大纲在浏览器中运行。可选的 AI 功能使用你配置的 API 连接。另一台设备登录同一个 Chrome 账号后，可通过通行密钥或配对码解锁共享连接。

可选的 Diao Bridge 适用于 Apple 芯片、macOS 27.2 及更新版本，提供标签旁提醒、遮挡时暂停的关闭倒计时和 Control + Tab 最近使用切换。

Diao 原名 Tab Cadence。通过同一个 Chrome 应用商店条目安装和更新。
