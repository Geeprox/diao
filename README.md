# Diao

Chrome 标签旁的本地提醒，以及 ChatGPT 页面内的批注、排队和大纲。

Diao 原名 Tab Cadence。通过同一 Chrome 商店条目升级后，原有的保存连接和设置可继续使用。Mac 助手提供标签旁提醒和 Control+Tab。参见[验证与发布说明](docs/publishing.md)。

## 从网页开始监听

在网页或选中的状态文字上点右键，选择「开始监听」。Chrome 150 起也可在标签条使用此入口。如果网页有明确的任务状态，监听会直接启动。其他页面提示你点一下当前状态的文字，下次监听相同网站和路径会复用这个位置。需要精确匹配等待和完成文案时，可以选择「手动填文案」。

页面结束忙碌、匹配到完成文案，或你点选的状态区域发生变化时，已启用的 macOS 标签提醒会显示薄荷色「可以继续了」。回到该标签即可接手。需要调整或停止监听时，可在侧栏「管理事项」找到该页。匹配到文案后仍需查看网页结果。监听随同一标签在窗口间移动。休眠后唤醒会恢复监听，Chrome 重启后也可恢复能唯一匹配且可读取的页面。

## 从标签条关闭或保留

启用 macOS 标签提醒后，在一个至少闲置 60 秒的后台标签上点右键，选择「30 秒后关闭，可保留」。浮标出现且可见时才累计 30 秒。切离 Chrome、浮标被遮挡或悬停浮标时暂停，恢复可见后接着数。点击浮标的「保留」即取消本次关闭。

正在使用、固定、发声、休眠、隐身、编辑、等待中、最近有操作或页面状态不明的标签受保护。结束前再核对标签身份、内容和安全条件。已关闭的页面可从「管理事项」的近期关闭记录重新打开网址。建议关闭可从管理事项发起。

## 在 ChatGPT 页内批注和排队

先停用旧的 ThreadDeck 油猴脚本，再在设置的「ChatGPT」中授权并启用，刷新已打开的对话。选中回答文字添加原位批注。回答生成期间，在 ChatGPT 原输入框按 Enter 将消息加入队列。当前回答明确结束时，扩展通过原发送按钮提交队首。问题上屏后只移除该条，等待这条问题的回答结束后再续发下一条。正在输入的草稿、编辑中的批注与不确定的发送状态会暂缓续发。批注数据保存在本机。排队草稿和发送回执与标签会话关联。文字和图片都按当前回答的终态判断。ChatGPT 返回限流时，自动队列等待冷却。

## 在对话中双指缩放

在已有提问的 ChatGPT 对话正文上捏合双指，正文围绕当前阅读位置收拢成概览，保留提问顺序、回答和章节。继续滚动浏览，张开双指回到对应原文，也可以点一条提问、回答或章节跳转。Esc 和「返回对话」回到原阅读位置。缩略消息沿用 ChatGPT 当前的主题、颜色和字体。

在对话设置关闭「对话区双指缩放」后，浏览器可照常缩放。右侧大纲的「概览」仍可打开会话速览。大纲直接显示已加载的提问、独立回复与回答章节。固定大纲后会自动补齐更早的网页历史，完成后返回原阅读位置；点击或滚动正文可中止补载。仍有历史尚未载入时，可用「补齐更早消息」继续。大纲和搜索会自动纳入新增内容。

在对话设置将「概览摘要」设为「提前准备」，前台会话空闲时即可用已配置的 OpenAI 连接生成逐轮摘要、主题和总览。准备好的内容会随捏合动画出现。选择「打开时生成」则在打开概览时请求。即使初次没有已识别的轮次，概览也会先打开。历史未齐时，概览利用 ChatGPT 网页自己的加载机制向前补齐，并回到原来的阅读位置。网页暂时无法补齐时，自动概括已读取的问答并标明范围。同一具体问题的连续追问可合成一条结论，每轮原文与章节仍可打开。正文长度合适的会话合并在一次请求内处理，长会话分批后再综合主题。完整与部分会话分别记录覆盖范围，会话更新时复用正文与顺序仍然相同的批次。同一份问答共用在途请求和缓存。「只看原文与缓存」仅显示本机索引与已有摘要。预制时还缺历史的会话会在首次打开概览后自动补齐。网页始终未提供更早内容时，概览会标示覆盖范围。

## 管理与设置

在普通网页按住 ⌘（Windows、Linux 为 Ctrl）从链接打开后台标签，链接会与来源页一起进入 Chrome 原生分组。再开的链接会进入同一组。首次分组用来源页命名，手动改名后按你设置保留。独立新开的标签保持原位。在「设置 → 标签」可关闭自动分组。

点击工具栏图标打开侧栏。管理事项显示待接手、等待和建议清理。通过「添加事项」选择本地监听，或按网站批量查找清理建议。可在所有窗口的普通网页中选择。固定、活跃、近期使用的网页可分析，实际关闭仍受保护。休眠和加载中的网页自然载入后才分析。浏览器内部页面无法读取，内网留在本机。也可直接右键网页「开始监听」。

在「设置 → 标签」选一次自动收纳间隔。长时间闲置的普通网页会进入当前窗口的 Chrome 原生「闲置标签」分组。点开分组或用 Chrome 标签搜索可返回，右键可取消分组。固定、播放音频、已有分组和需要接手的页面留在原位。自动收纳只调整分组，页面保持打开。

## 模型连接

在「模型连接」保存一份 OpenAI API Key，Decisions 和 Responses 共同使用。Decisions 使用指定模型，Responses 可以调整模型。兼容服务按自己的 HTTPS 地址保存独立连接。保存时自动验证一次。

| 协议 | 路径 | 用途 |
| --- | --- | --- |
| OpenAI Decisions | /v1/decisions，gpt-6-luna | 固定选项状态分类 |
| OpenAI Responses | /v1/responses | 结构化建议与简短原因 |
| OpenAI 兼容 | /v1/chat/completions | 支持该协议的其他服务商 |

运行时密钥位于可信扩展的会话存储，并绑定 API 域名。「此设备」使用加密的本机 IndexedDB，重启与更新后自动恢复。也可粘贴密钥或从本机 .env 导入。原有 macOS 钥匙串保存方式仍可恢复。

### 在多台设备使用同一连接

原设备选择「Chrome 同步」。点「保存连接」使用可在两台设备间访问的通行密钥，或点「用配对码保存」取得设备配对码。新设备以同一账号开启 Chrome 扩展同步，打开「模型连接」，验证通行密钥或输入配对码一次，以后随 Chrome 启动自动恢复。遗失配对码时，可在已连接的设备生成新码，再为其他设备配对。旧版的同步口令仍可使用。Chrome 扩展同步只保存加密连接及解锁所需的公开参数。移除同步后，其他设备收到更新时会断开。

发送预览包括标题、去掉查询参数和片段的地址、最多 1600 字符正文和有限状态信号。存在编辑器时不提取正文，批量分析也会跳过正在编辑、播放或等待任务的页面。网页内表单值不会发送。标题和网址路径仍可能含私人信息，发送前需要检查。

### 控制调用用量

- 本地监听、重复页识别、分组和 MRU 切换不调用模型。
- 批量分析由你确认一次范围后运行，默认只处理本轮页面。相同内容与相同协议/地址/模型，跨标签复用 24 小时内的结果。
- 单页或批量预览可选择后续自动复查，仅覆盖本次同意的页面。页面闲置至少 10 分钟，每 5 分钟最多检查一个候选；内容相同不调用模型。
- 批量队列单并发，通常间隔约 3 秒；后台工作线程休眠时由至少 30 秒的闹钟唤醒。点击暂停后允许当前请求结束，之后不再发起下一页。遇到 429 按模型服务给出的时间暂停，冷却结束后处理后续页面。结果未知的请求保留为未完成。
- 整个 Chrome 重启后批量队列暂停，后续自动复查停用；确认后可继续未处理页。扩展重载或工作线程中断时，结果未知的请求标为未完成，避免重复计费。本地及内网页面不进入自动队列。
- 默认单并发、同页间隔 120 秒，相同内容 24 小时复用判断；失败不自动重发。调用次数和 token 仅做用量记录，不设置扩展侧的每日硬上限。
- Responses/Chat 输出上限 512 token；Decisions 一个固定选项问题。每日用量按北京时间记录。
- 费用单价由使用者填写，未配置时为 0。估算不是账单或服务商侧的美元硬限额。

## macOS

开启“Control + Tab 按最近使用切换”，按住 Control 连按 Tab 遍历，Shift 反向，松开 Control 确认；Escape 返回原页。冻结一次手势中的使用顺序，不移动标签栏，只在当前 Chrome 普通窗口生效。切换器优先使用 Chrome 里的站点图标，内置页面使用系统图标。

辅助程序使用公开 CGEventTapCreateForPid 限定 Chrome 进程，只识别快捷切换所需按键与取消手势，不读取或记录输入文字。安全输入、权限不足、窗口不符时保留普通键盘行为。

原生提醒要求窗口几何和唯一标题匹配。竖向标签显示横向提示，横向标签显示竖向提示；重复、不可见或前台不符时隐藏，并保留侧栏路径。0.3.0 支持关闭环、悬停暂停和“保留本次”按钮；普通完成提示保持鼠标穿透。关闭提醒面板不激活应用，不接管正常输入。

Mac 助手适用于 Apple silicon、macOS 27.2 或更新版本。模型连接可以保存在当前 Chrome 配置或通过 Chrome 同步。选择保存到 macOS 钥匙串时，需要支持钥匙串的稳定签名助手。

## 开发与安装

需要 Chrome 120+ 和 Node.js 22+。在 Chrome 扩展管理页加载 `extension/`，改动后重新加载。构建 Mac 助手另需 Xcode Command Line Tools。

```sh
npm test
python3 -B scripts/package_store.py --version 0.4
```

用 `node tests/local-journey.cjs` 在独立 Chromium 配置中验证合成网页和 ChatGPT 对话。先安装 Playwright 和 Chromium，或设置 `TABPILOT_PLAYWRIGHT_PATH` 指向已有 Playwright 模块。设置 `TABPILOT_CHAT_LAYOUT=modern` 可验证当前 ChatGPT 布局。

设计约定见 [DESIGN.md](DESIGN.md)。Mac 助手的构建和安装见[发布说明](docs/publishing.md)与[Mac 助手安装说明](docs/mac-install.md)。

官方依据：[Decisions](https://developers.openai.com/api/docs/guides/decisions)、[Chrome Side Panel](https://developer.chrome.com/docs/extensions/reference/api/sidePanel)、[Native Messaging](https://developer.chrome.com/docs/extensions/develop/concepts/native-messaging)、[Tabs](https://developer.chrome.com/docs/extensions/reference/api/tabs)。

## 连接保存与恢复

首次填写或从本机文件导入，选择「当前 Chrome 配置」或「macOS 钥匙串」，再点「保存连接」。界面显示保存成功后，同一配置中的扩展会在更新或重启后恢复密钥。仅本次会话模式适用于临时连接。

0.5.0 为旧版条目提供一次性迁移：点“解锁并恢复连接”，在本机允许访问；程序将旧密钥复制到稳定签名创建的新条目，保留旧条目供恢复。真实迁移、扩展重载和完整重启 Chrome 后的静默恢复均已验证。Chrome 更新后若出现原生连接校验失败，请完整退出并重新打开 Chrome。

遇到暂时锁定时使用恢复按钮；不要重新申请 Key。API 地址不匹配、主动移除连接、卸载扩展后新建安装身份等情况与普通重载不同。主动“移除连接密钥”会删除当前安装的新旧条目以及运行时值；无法删除时保留错误，不虚报成功。
