Pick up where you left off.

Get back to background tasks, keep related Chrome tabs together, and find the part of a long ChatGPT conversation you need.

Add to Chrome

Tab reminders

Right-click a task page and choose Start watching. Diao lets you know when it’s ready. If the page needs help identifying the status, select the status text once.

ChatGPT outline and summaries

Search questions and answer sections, jump to the original message, or pinch to open the overview. Connect your OpenAI key to prepare topic and answer summaries.

Tab groups

Keep newly opened links with the page they came from. With a model connection and your permission, Diao can also group related work across websites and tuck completed work into Idle tabs.

Getting started

Do I need a Mac?
Chrome handles page watching, tab groups and the ChatGPT tools. Diao Bridge adds tab-side reminders, a visibility-aware countdown and Control + Tab switching on Apple silicon Macs running macOS 27.2 or later.
How do I move my OpenAI connection?
Choose Chrome Sync under Model connection. On a new device with the same Chrome account, unlock the saved connection with a passkey or a pairing code. You can keep a separate key on one device.
Is this the same extension as Tab Cadence?
Yes. Diao is the new name for Tab Cadence. Install or update it from the same Chrome Web Store listing.
